Política de Privacidade

Estudio · atualizada em 2 de novembro de 2026

O Estudio é um aplicativo de uso pessoal. Ele roda apenas no computador do dono do canal Brick Cities e não é usado por outras pessoas.

Quais dados o aplicativo acessa

Com a autorização do dono da conta, o aplicativo usa a API de Dados do YouTube para:

  • Enviar vídeos ao canal autorizado (permissão youtube.upload);
  • Ler as informações básicas do canal, como nome e número de vídeos, para confirmar o canal certo antes de cada envio (permissão youtube.readonly).

Como os dados são guardados

O código de acesso fornecido pelo Google fica guardado apenas no computador do dono do canal. Nenhum dado é enviado a servidores do Estudio, porque o Estudio não tem servidores.

Compartilhamento

O aplicativo não vende, não compartilha e não transfere dados a terceiros. Os dados não são usados para publicidade.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser cancelado a qualquer momento em myaccount.google.com/permissions.
